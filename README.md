# Sales-Trend-Analysis-Using-Aggregations

## Time-Based Sales Analysis Using SQLite in Jupyter

This project demonstrates how to analyze time trends in sales data using **SQLite** within a **Jupyter Notebook**. It uses the "Superstore" dataset to explore monthly, quarterly, and yearly patterns in revenue and order volume.

---

## Objective

- To perform **time-based analysis** on sales data by:
- Grouping by **month**, **quarter**, and **year**
- Measuring **total revenue**, **order volume**, **average order value**, and more
- Segmenting trends by **Region**, **Category**, **Sub-Category**, and **Shipping Mode**

---

## Tools & Technologies

- Python 
- SQLite (via `sqlite3`)
- Pandas
- Jupyter Notebook
- Excel Dataset (`superstore dataset.xlsx`)

---

## Key Analyses Performed

- Monthly and Yearly Revenue Trends  
- Quarterly Order Volume  
- Weekly Sales Volume  
- Revenue Trends by **Region** and **Category**  
- Average Order Value over Time  
- Monthly Customer Growth  
- Average Shipping Delay by Month  
- Top Months by Revenue

## How to Run

1. Clone this repository  
2. Open the notebook in Jupyter  
3. Ensure the Excel file is in the same directory  
4. Run the cells step by step — SQLite will create a database and perform all queries live
